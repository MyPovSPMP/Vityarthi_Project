# 🎲 Casino Dice Betting Game

## Overview

A simple Python command-line casino game where players bet virtual money on the outcome of a six-sided dice roll. The project demonstrates basic Python programming concepts through an interactive game.

## Features

* 🎲 Random dice rolling
* 💰 Virtual casino balance
* 🎯 Number-based betting
* 🏆 Win and loss system
* 💵 Deposit and withdrawal options
* 🔄 Continue or exit the game
* ⚠️ Input validation
* 🎨 Colored terminal output
* 🛑 Casino bankruptcy condition

## Technologies / Tools

* **Python 3**
* **Colorama** – Terminal colors
* **Random** – Dice generation
* **OS & Subprocess** – Terminal clearing

## Installation

1. Install Python 3.
2. Install Colorama:

```bash
pip install colorama
```

3. Download or clone the project.
4. Open the project directory.

## Running the Project

Run:

```bash
python casino.py
```

## How to Play

1. Enter the amount you want to bet.
2. Choose a number between **1 and 6**.
3. The program rolls the dice.
4. If your number matches the roll, your bet is doubled.
5. Otherwise, you lose the bet.
6. Choose whether to continue playing.
