# Problem Statement

The project aims to develop a simple command-line casino game that allows users to bet virtual money on a dice roll.

It combines Python concepts such as loops, conditions, functions, random numbers, user input, and exception handling into one interactive application.

# Scope of the Project

The project includes:

* Virtual betting and casino balance.
* Dice rolling from 1 to 6.
* Win/loss calculation.
* Deposit and withdrawal.
* Input validation.
* Continue or exit functionality.
* Colored terminal interface.

The project does not involve real money or real gambling transactions.

# Target Users

* Python beginners
* Programming students
* Students practicing Python concepts
* Developers learning through small projects

# High-Level Features

1. **Dice Rolling** – Generates a random number from 1–6.
2. **Betting System** – Allows users to place virtual bets.
3. **Win/Loss System** – Determines the result based on the dice roll.
4. **Balance Management** – Supports deposits and withdrawals.
5. **Input Validation** – Handles invalid user input.
6. **Game Control** – Allows users to continue or exit.
7. **Terminal UI** – Uses Colorama for colored output.
